## Проверки после ошибки

Локальный прогон с настоящим архивом базы знаний, одним синтетическим вопросом и синтетическим HTTP-ответом создаёт корректный CSV с сохранённым ID `001`. Это проверка входного контракта, не качества модели.

При сравнении обработки окружения с официальным образцом воспроизведены отличия:

| Синтетическое окружение | Наш текущий Settings | Образец организаторов |
|---|---|---|
| Корректные LLM_BASE_URL, LLM_API_KEY, LLM_MODEL | Принимает | Принимает |
| MAX_TOKENS равен строке MAX_TOKENS | ValueError | Значение по умолчанию |
| Адрес указан только в BASE_URL | ValueError | Принимает alias |
| LLM_BASE_URL равен своему имени, OPENAI_BASE_URL корректен | ValueError | Использует корректный alias |

**Это возможные причины несовместимости, а не доказанная причина платформенной ошибки.** Для подтверждения нужен журнал среды организаторов либо исправленный согласованный прогон. Отдельно требуют проверки расположение/имена файлов и CSV-колонки. Исходные материалы организаторов в git не добавлены.

## Выбранные изменения

1. Контекст сохраняет исходные hits и полные guards, затем добавляет промежуточных
   родителей найденных подразделов. Части одного родителя помещаются только вместе.
   Это устраняет воспроизведённую потерю объяснения аудита и модернизации. Лимиты
   14000 / +4000 сохранены; правило не содержит ID демо или названий продуктов.
2. Невосстановленный `finish_reason=length` больше не превращается в успешный ответ
   после обрезки по предложению. Синтетическое воспроизведение показывало сохранение
   цены с потерей начатого условия. Теперь вызывающий код получает безопасную ошибку;
   batch сохраняет ненумерический ответ из источника. Максимум три HTTP-попытки,
   увеличение токенов только при оставшейся попытке, глобальный deadline сохранён.
3. SYSTEM сообщает подтверждённые факты прямо, сохраняет степень уверенности и все
   существенные условия источника. Сокращаются вводные, а не обязательные оговорки.
   Фактическая строка SYSTEM побайтно равна проверенному safe-v1.

## Отклонённые варианты

- Raw H1: замена всех условий одним «ключевым» ослабляет достоверность.
- 20k/8k: средний контекст +26.3%, но известный пропуск другого документа в ID18
  не устранён; добавляются неуместные для узких вопросов ценовые разделы. Живой
  выигрыш не установлен, лимиты не увеличены.
- Self-refine Ромы: Глеб воспроизвёл отсутствие заявленного временного резерва;
  семантическая сохранность правки не проверена. Дополнительный вызов не включён.

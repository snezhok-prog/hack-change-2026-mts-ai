## Воспроизведение runtime-проверок

```sh
python docs/notes/reproduce-runtime-findings.py
```

Скрипт использует только синтетические документы и `httpx.MockTransport`, не читает
`.env` или реальную базу и не обращается к провайдеру. Результаты, версия и хеши
ядра пишутся в игнорируемые `work/runtime-review-results.json` и `.md`.
`XFAIL` обозначает воспроизведённый известный дефект, `XPASS` — его исправление;
нулевой exit code означает корректно выполненный диагностический прогон, а не
отсутствие дефектов или готовность к победе. Для решения о кандидате читать
отдельные checks, а не только код выхода.

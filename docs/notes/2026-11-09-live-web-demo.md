# Первый живой прогон локального веба

Источник: разрешённое владельцем подключение OpenRouter и проверка в Chrome, 2026-11-09.

## Подключение

- Ядро контейнера: `1e1f242`; настройка Compose: `ca13bbb`, PR #11.
- База знаний смонтирована локально: 235 фрагментов, поиск работает.
- Провайдер: OpenRouter, бесплатный маршрут `openrouter/free`. Конкретная модель может меняться; это не конкурсная Qwen.
- Отдельный ключ на 7 дней, лимит расходов $0. Секрет только в игнорируемом `.env`, отсутствует в коде и ZIP.
- `MAX_TOKENS=4096` для локального демо; Compose теперь передаёт это значение в контейнер. Прежнее значение по умолчанию 1200 сохранено.

## Фактические результаты

Первый ответ при прежнем бюджете получен за 12384 мс, но его конец оборван. После изменения бюджета начат новый диалог:

| Действие | Результат |
|---|---|
| Вопрос об учёте электричества на небольшом складе | Живой полный ответ, 6645 мс, 8 источников |
| Уточнение мощности, отказ от телефона, запрос точного процента экономии | Живой полный ответ, 13035 мс, 8 источников; точный процент не выдуман, консультация продолжается без телефона |
| Выдуманные контакты и сохранение заявки | Заявка сохранена с контекстом; UI явно подтверждает отсутствие отправки в МТС |
| Проверка ключа после прогона | usage=0, limit=0; использовано 3 из 50 бесплатных запросов, осталось 47 |

Отдельная проба `google/gemma-4-31b-it:free` получила HTTP 429 после ограниченных повторов; локальный веб оставлен на `openrouter/free`. Бесплатный доступ имеет квоты и не гарантирует постоянную доступность.

Это smoke-проверка доступности и двух сценариев, не оценка достоверности всех продуктовых утверждений или качества конкурсной модели. Тексты ответов, исходная база и скриншот остаются локальными. Публичного хостинга нет: `localhost` доступен на компьютере владельца.

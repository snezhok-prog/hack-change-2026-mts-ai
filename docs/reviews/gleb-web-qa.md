## Результат

Добавлено 8 проверок в tests/test_web_qa_independent.py.
Полный набор на указанном снимке: **43 tests, OK** (35 существующих + 8 новых).
В покрытых сценариях дефекты не воспроизведены; это не утверждение об отсутствии
всех ошибок и не проверка качества живой модели.

| Проверка | Что подтверждено |
|---|---|
| Чередование двух сессий | Каждая повторная реплика получает только свою историю |
| Два конкурентных сообщения одной сессии | Запросы перекрываются на входе ASGI; ядро выполняется последовательно, второй ход видит первый |
| Три конкурентные сессии и четвёртая | Первые три одновременно входят в синтетическое ядро, четвёртая получает 429 без записи сообщения; после освобождения запрос проходит |
| Четыре последовательные ошибки модели | 503 без приватного текста ошибки, без фиктивного assistant; слоты освобождаются, заявка до успеха получает 409; последующая консультация и заявка проходят |
| Шесть одинаковых конкурентных заявок | Все ответы с одним ID, одна сохранённая заявка; изменение компании получает 409 без перезаписи |
| Сохранение истории после завершения процесса | Отдельный Python-процесс пишет две сессии и заявку, завершает работу; новое приложение читает ровно те же данные и метаданные. Архив содержит сессию с заявкой и без неё |
| Некорректные запросы и неизвестная сессия | 422/404 не меняют другую сессию; последующий корректный запрос работает |
| Запуск без модели | ready=false, сообщение даёт 503, заявка — 409; в истории user/error |

Тест конкурентной загрузки выбирает разные полосы существующих session-locks,
чтобы случайная коллизия hash(id)%64 не подменяла проверку лимита.
Порядок конкурентных событий задаётся threading.Event, не длительными sleep.
Тайм-ауты служат ограничением зависания теста, не измерением скорости API.

## Границы проверки и следующий шаг

- Только синтетические ядро, ответы и контакты. Внешний API не вызывался.
- HTTP проверен через ASGI TestClient, не через Chrome или реальную сеть.
- Перезапуск проверен через завершение отдельного Python-процесса и повторное чтение
  SQLite. Аварийное выключение, потеря диска, Docker restart и восстановление после
  повреждения SQLite этим набором не проверяются.
- Многопроцессный запуск и публичный доступ вне текущего localhost scope.
- Перегрузка проверена на четырёх запросах; нагрузочная ёмкость и p95 не измерялись.
- Нет зависимости от закрытой базы организаторов, секретов или Telegram.
- Новых доказанных дефектов web.py/storage.py в этих проверках нет, поэтому issues
  с вымышленными багами не создавались.

Рома — ревью/слияние. Codex интеграции — после предоставления API выполнить
живой веб-сценарий; Глеб — обновить презентацию по подтверждённым результатам.
Оценка оставшейся работы: ревью 20–40 минут, живая репетиция 1–2 часа после доступа.

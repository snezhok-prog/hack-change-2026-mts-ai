## Пересборка

Python 3.11+, пакет ReportLab 4.4.9 и шрифты DejaVu Sans.
Зависимости нужны только для документов и не входят в конкурсный ZIP.
Пакет устанавливайте в отдельное окружение:

```sh
python -m venv work/deck-venv
work/deck-venv/bin/python -m pip install reportlab==4.4.9
work/deck-venv/bin/python docs/demo/build_presentation.py --output work/presentation-draft.pdf
```

По умолчанию шрифты берутся из /usr/share/fonts/truetype/dejavu.
На другой системе передайте --font-dir с каталогом, содержащим
DejaVuSans.ttf и DejaVuSans-Bold.ttf. Для экспорта в репозиторий после проверки
укажите --output docs/demo/presentation-draft.pdf.

## Что проверено

PDF открывается; содержит восемь страниц 1280×720. Русский текст извлекается,
текстовые блоки не выходят за границы страниц. Ссылка на репозиторий на первом
слайде кликабельна. Все страницы визуально просмотрены на контактном листе.
В макете только авторский текст и схемы; нет закрытой базы, скриншотов ответов
модели, секретов или реальных контактов.

Успешный CI на слайде 5 относится к конкретному коммиту 2ed811b и run 42684281251.
Это не результат живой модели или автоматической оценки организаторов.

# Статус — 2026-11-09

Реализован начальный прототип. Проверено 25 автоматических тестов (`python -m unittest discover -s tests -v`): retrieval, CSV, обработка API-ошибок, сессии/заявки/архив, Git-канал сообщений с сохранением dirty worktree, воспроизводимый ZIP и запуск распакованного submission отдельным процессом через локальный HTTP fixture. `pip check` не нашёл конфликтов. API-ответы в тестах синтетические; они проверяют контракт, а не качество модели.

В реальном Chrome проверены localhost-интерфейс, отправка вопроса без настроенного API (честная ошибка), новый диалог (очистка контекста), мобильная компоновка при viewport 390×844; горизонтального переполнения нет. Предупреждения в консоли относятся к стороннему browser extension, не к приложению. Полный браузерный сценарий с живой моделью ещё не пройден.

Добавлены `scripts/build_submission.py`, Dockerfile, Compose и `.env.example`. Сборщик включает только пять разрешённых корневых файлов. ZIP проверен локально, на платформу не загружался. Docker отсутствует на машине; конфигурация подготовлена, запуск контейнера не подтверждён.

## Что остаётся проверить/сделать

- Реальный API организаторов: ответы, тариф/доступ, актуальный model ID, latency, качество и факты на демонстрационных вопросах. Ключей в репозитории нет.
- Полный браузерный прогон с живой моделью и запуск Docker на машине с установленным runtime.
- Whitelist зависимостей платформы и запуск в её среде. Базовый submission использует только httpx из примера организаторов; веб-зависимости в submission не нужны.
- Укрепление deadline: текущие таймауты HTTP ограничивают сетевое ожидание по этапам, но не дают жёсткий предел общего wall-clock при медленной потоковой передаче. До сдачи нужен тест общего бюджета.
- Семантический поиск/reranker и качество диалогового retrieval: сейчас BM25 и последние пользовательские реплики. Результаты качества ещё не измерены.
- Публичное размещение требует отдельной защиты доступа к сессиям, rate limits и правил обработки персональных данных. Сейчас localhost + выдуманные контакты.

Независимый обзор PAL не завершился из-за лимита бесплатного провайдера (413). Serena не активировала Python language server в текущей сессии; использованы чтение файлов, rg и тесты. Эти ограничения не заменены утверждениями об успешной внешней проверке.

# Архитектура первой итерации

Владельцы модулей — в [AGENTS.md](../AGENTS.md). ИИ-ядро (`retrieval`, `consultant`, `model_client`, `solution`) ведёт Рома; план его развития — [AI-CORE.md](AI-CORE.md).

- `retrieval.py`: безопасное чтение ZIP без распаковки, секции Markdown, BM25, запрос по пользовательским репликам.
- `model_client.py`: HTTP-клиент совместимого chat/completions API, env-конфигурация, ограниченные повторы, безопасные сообщения ошибок.
- `consultant.py`: общее stateless-ядро. Контекст из retrieval + диалог → ответ, источники и время. Системный промпт ограничивает факты базой, но это не доказательство отсутствия галлюцинаций.
- `solution.py`: контракт CSV, параллельные независимые вопросы, атомарная запись результата. Эти четыре модуля и `requirements.txt` нужны платформе в корне ZIP.
- `web.py`, `storage.py`: FastAPI, SQLite, изолированные сессии, постоянная история, заявка и краткое содержание. Один процесс Uvicorn.
- `static/`: HTML/CSS/JS без сборщика. Данные отображаются через textContent. В начальной реализации React не требуется.

## HTTP-контракт для frontend

| Метод и путь | Вход | Результат |
|---|---|---|
| GET `/api/health` | — | ready, mode, provider_verified |
| POST `/api/sessions` | — | 201: id |
| GET `/api/sessions/{id}` | — | id, created_at, messages, lead |
| POST `/api/sessions/{id}/messages` | text | answer, sources, elapsed_ms |
| POST `/api/sessions/{id}/lead` | name, phone, company, test_data_confirmed | 201: сохранённая заявка |
| GET `/api/admin/sessions` | Authorization: Bearer ADMIN_TOKEN | последние 100 диалогов, включая без заявки |

Ожидаемые ошибки: 401 — архив без ключа; 404 — неизвестная сессия; 409 — заявка до консультации или изменение уже сохранённых контактов; 422 — валидация; 429 — заняты слоты; 503 — модель не настроена/недоступна. В ошибке поле detail. Повтор идентичной заявки возвращает тот же id.

Каждая загрузка страницы создаёт новый контекст. История остаётся в SQLite. ID сессии — случайный секрет доступа к её содержимому; текущая версия предназначена для localhost и тестовых данных, не для публичного продакшена.
